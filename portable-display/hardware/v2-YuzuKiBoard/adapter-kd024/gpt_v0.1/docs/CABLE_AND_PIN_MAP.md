# FFC 条件线序与 J1／J2 管脚映射

**HOLD：没有实物证据前，不把同面线或反面线直接等同于恒等或反序。** 两种线缆分别列出逐脚表，表中恒等／反序是两种电气假设，不是线缆已确认属性。实际映射全列待确认；以两端连接器实际编号、安装面、接触面和电缆走向逐脚蜂鸣为准。

本候选 PCB 按“主板 n → J1 n”的**恒等电气映射**设计，尚未批准具体同面／反面线型号。缺少证据时不能用试插通电来确定方向。表中板网 NC 表示本板不连接，并不表示该主板引脚一定无电压。

来源：原始任务书 J1 表、原板原理图、屏规格管脚表，以及 DESIGN_NOTES 中 [S1]–[S4]。
