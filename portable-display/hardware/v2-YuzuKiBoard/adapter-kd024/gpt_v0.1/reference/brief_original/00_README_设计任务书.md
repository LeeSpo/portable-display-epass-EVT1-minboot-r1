# 蜥蜴 → KD024 最小 DSI 转接板 设计任务书 v0.1

请先完整读完本文件，再看附带资料。**凡是资料里查不到的数据，一律不许编，在说明里标"待确认"。**

## 0. 目标
用 KiCad 8 设计一块最小 DSI 转接板，把 **柚木PI蜥蜴（YuzukiHD Lizard，V851s 开发板）** 接到 **KD024EGOIN152-01 屏（驱动芯片 RM690B0，2.4 英寸 AOD 屏）**，用来验证 MIPI DSI 1-lane 能不能点亮这块屏。板上只做显示这一部分，不放电池、传感器和按键。

## 1. 板子规格与设计规则
- 4 层板，厚 1.0mm，嘉立创叠层 JLC04101H-3313。层分配：Top 走信号，In1 为 GND，In2 为电源和 GND，Bottom 为 GND 和少量走线。
- 只在顶层贴片，**不做盘中孔**，不做树脂塞孔（POFV）。元件优先用嘉立创基础库，被动件用 0402 或更大，电源测试用的 0Ω 电阻用 0603。
- 需要手焊的元件（排母等）标 DNP，并且不放进 CPL。
- 线宽和线距都不小于 0.15mm，差分线按第 4 节算出来的值走。
- 过孔孔径 0.3mm、焊盘 0.6mm。过孔边到焊盘边不小于 0.15mm，过孔不能打在焊盘上。
- 铜皮离板边不小于 0.3mm。

## 2. 接口
### J1，接蜥蜴：24P 0.5mm FPC 座（蜥蜴那边是 FH34SRJ-24S-0.5SH）
| 脚 | 信号 | 处理 |
|---|---|---|
| 2 / 3 | D0N / D0P | 接到 J2 的 D0 |
| 5 / 6 | CKN / CKP | 接到 J2 的 CLK |
| 8 / 9 | D1N / D1P | **不接**，也不要拉出悬空的短线 |
| 11 / 12 / 14 | 3V3 | 三个脚并在一起用，只给 1V8 LDO 和逻辑电路供电 |
| 18 | DSI_RST（PD8，3.3V 电平） | 屏的复位，电平见第 4 节 |
| 16 / 20 / 21 | — | 悬空不接 |
| 22 / 24 | LEDK / LEDA，背光高压 | **悬空不接**，旁边不能走差分线 |
| 其余 | GND | 每个脚旁边都打一个地过孔接到 In1 |

**触点朝上还是朝下还没确认**，所以原理图要用一个网络映射，同时出"同面线"和"反面线"两种情况各自的逐脚线序表，并说明你的版图按哪一种画。等我们拿到实物拍照后再最终确定。

### J2，接屏：45P 0.3mm FPC 座
参考料号 Molex，LCSC `C5365339`，图纸见 03_datasheets/molex_SD-502598-003.pdf。
- 管脚定义以 02_kd024_screen 里的规格书为准，只接 D0 和 CLK 两对。
- 电源脚（VCI、VDDIO、ELVDD、ELVSS 等）按规格书接到第 3 节的各路电源。
- 规格书要求的其他控制线（TE、SWIRE 等）都要处理，用不到的引出到测试点。

### H1/H2：接蜥蜴的排针，作为固定点兼电源
- H1 是 13 脚，H2 是 5 脚。按蜥蜴 Gerber 里的实际焊盘坐标摆放。两排中心相距 19.913mm，**不在 2.54mm 网格上**，不能按网格估。
- 孔径 1.0mm，焊盘 1.7mm。
- 只用到 GND、H1-13（VBUS 5V）和 H2-3（3V3）。H1-1、H1-12、H2-1 都是 GND。

## 3. 电源
- **TPS65631**：先查手册里允许的输入电压。如果能直接接 5V，就从 H1-13 取电；不能的话，从 H1-13 经一颗 LDO 降到约 3.6V 再给它。**不要用蜥蜴的 3V3 给它供电**，屏最大功耗约 526mW，蜥蜴的 3V3 我们暂按最多 300mA 算。
- TPS65631 输入端靠近放 10µF 加 100nF 的电容，外围电感和电容按手册的典型电路配。
- **说明里要写电感的选型依据**：额定电流、饱和电流、直流电阻，要能撑住屏最大功耗时的峰值电流。不要只写"按典型电路"。
- 屏的 1V8（VDDIO）用一颗小 LDO 从 3V3 取电。屏的 VCI 按规格书要求取电。
- LCD_EN，也就是 TPS65631 的使能，用 10k 下拉到地，保证上电时偏压默认关着。这根线的控制脚要引到测试点或排针。
- 5V 上的电容耐压不低于 10V，每颗 IC 的电源脚旁边都放 100nF。
- 下面几路都要留测试点：5V 输入、TPS65631 输入、ELVDD、ELVSS、1V8、3V3。
- TPS65631 输入和 1V8 LDO 输入各串一颗 0603 的 0Ω 电阻。第一次上电时可以拆掉它单独测电流。

## 4. 信号（MIPI DSI）
- 线宽线距要用嘉立创阻抗计算器，按 JLC04101H-3313、顶层参考 In1 GND，算出 100Ω 差分的值。说明里写清楚算出来的数和用的参数，不许估。
- 等长：同一对的 P 和 N 长度差不超过 0.15mm；D0 和 CK 两对之间的长度差不超过 1mm。说明里列出每根线的实际长度。
- J1 到 J2 每一对都是 P 接 P、N 接 N，不许对调。差分线全程走在顶层，不打过孔，底下的 In1 GND 要完整，不能有分割。
- D0/CK 离 TPS65631 的开关脚和电感至少 3mm，也不能从它们下面穿过。
- 差分线两侧每隔几毫米打一排地过孔。拐角一律用 45° 或圆弧，同一对的两根线一起拐。
- **复位电平**：PD8 是 3.3V 的。查 KD024 规格书里复位脚要求的电平，如果是 1.8V，就加分压或电平转换，并在说明里写出依据。
- 说明里要附一张 D0/CK 走线的截图，标出线宽、线距和长度。

## 5. 机械
- 四角各放一个 M2 安装孔（孔径 2.2mm，非金属化孔），孔边 1.5mm 以内不放件、不走线。
- J1 放在和蜥蜴 FPC 座同一侧的板边，开口朝外，方便排线做 U 形回折。蜥蜴的 FPC 座在它的底面。
- J1、J2 座子开口的一侧 2mm 以内不放件，留出插排线和翻锁扣的空间。排母周围 1.5mm 以内不放贴片件。
- J1、J2 的焊盘照料号的规格书画，**不能用 KiCad 自带的通用封装凑合**。说明里要写清楚用的是哪份规格书的哪一页，以及锁扣在上面还是背面。
- 丝印要标出 J1/J2 的 1 脚，并用箭头标出排线插入的方向；TPS65631 和 LDO 标出 1 脚圆点。丝印不能压在焊盘或过孔上。
- 在板子的对角放两个光学定位点（Fiducial）：1mm 铜点、2mm 开窗。
- 板子越小越好。蜥蜴本身是 52.4 × 23.2mm，没有安装孔。

## 6. 交付物
1. KiCad 工程（.kicad_pro、.kicad_sch、.kicad_pcb，以及自建的封装库和符号库），DRC 和 ERC 都要 0 错误。如果有保留的豁免，逐条说明原因。
2. `adapter_v0.1_gerber.zip`，里面要有：
   - 四层铜：Top、In1、In2、Bottom（少了内层，嘉立创会按 2 层板处理）；
   - 正反两面的阻焊和丝印；
   - 顶层钢网（Paste）；
   - 板框 Edge.Cuts，必须是一条闭合的线。
3. 钻孔分两个 Excellon 文件：金属化孔（PTH）一个，非金属化孔（NPTH）一个。钻孔和 Gerber 用同一个原点，单位都是毫米。
4. `adapter_v0.1_bom.csv`，表头 `Comment,Designator,Footprint,LCSC`，每个位号都要和 PCB 上的对得上。DNP 的件单独列出来，标"不贴"。
5. `adapter_v0.1_cpl.csv`，表头 `Designator,Mid X,Mid Y,Layer,Rotation`，只有 Top 面的件，不能有 DNP 的件。
6. Gerber、BOM、CPL 必须从同一版 PCB 导出。
7. 说明文档 `DESIGN_NOTES.md`，要写清楚：
   - 每个元件的选型理由，以及是基础库还是扩展库的料；
   - J1 到 J2 的逐脚线序表，同面线和反面线两种都要有；
   - 阻抗计算的参数和结果、每根差分线的长度；
   - 电感的选型依据；
   - 所有"待确认"的假设，例如触点方向、复位电平、TPS65631 的输入电压上限、蜥蜴 3V3 的电流余量、排线长度。
8. 截图：
   - 正面 3D；
   - D0/CK 走线，带尺寸标注；
   - J1、J2、TPS65631 的 1 脚和旋转角度，用 KiCad 3D 或者嘉立创的贴片预览。
9. DFM 自查表：把本文件第 1、4、5 节的每一条逐项写"满足"或"不满足"，不满足的要写原因。

## 7. 不许做的事
- 没查到的数据不许编。
- 不许接 D1，不许接背光高压脚 22、24。
- 不许用蜥蜴的 3V3 给 TPS65631 供电。
- 不许做盘中孔，不许在底面放件。
- 不许擅自换屏、换芯片或改接口方案。真觉得需要改，写进说明里，并给出理由。
