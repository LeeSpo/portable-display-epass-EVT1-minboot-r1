# 后续布线约束与顺序

**这是布线计划，不是已完成的布线验证。当前铜线段与过孔均为零。**

## 1. 先修网络，再定线路

先处理电气报告中的 U6、VMID、U2 供电和显示控制问题。修正原理图后同步 PCB，保留本版主要功能区，但允许周边电容、电阻跟随真实引脚关系微调。不要在错误网络上追求“全部拉通”。

随后核对封装及实际插拔方向。FPC 位置尤其要结合屏幕展开机械图、接触面、针 1 方向和折回后的坐标确定。当前 J4 后方的机械预留不是屏厂批准的插接空间。

## 2. 四层与参考面

提议的层用途为：F.Cu 信号及局部电源，In1.Cu 连续 GND，In2.Cu 连续 GND，B.Cu 信号及较宽电源连接。两层 GND 区域已创建但没有填充；当前板厚沿用输入文件，并未建立经板厂确认的介质叠层。

这不是唯一可行的叠层。其目的在于给正反两面布线提供相邻参考面，同时不让高速线跨过任意切割的电源平面。电源在外层用短宽铜连接，实际线宽、过孔数量、压降、温升和电流能力需再计算。

项目中的 `HS_IMPEDANCE_TBD` 和 `POWER_PROVISIONAL` 名称就是待定标记。0.127 mm 的差分线宽/线隙和 0.60 mm 的电源线宽只是可编辑占位值，不是已经求解的阻抗或载流能力。

## 3. 电源局部回路优先

U1 周边应先完成 VIN 去耦、开关脚—电感—输出电容、地回流和反馈取样。SYS/BAT 电容要回到对应引脚；不能把 VREF、VMID、VSYS 的电容混作同一类。开关节点铜面积要克制，不能为了“宽松”拉成长线。

U10 按 TI 布局要求优先保持输入电容、两路开关节点、输出电容的短回路；功率回路优先同面连接，反馈从输出电容处取样，避开开关节点。裸露焊盘接地、散热过孔以及过孔防吸锡工艺需和封装及贴片工艺共同审核。

这些原则引用自器件制造商资料，具体网络和值仍以审核后的原理图为准。当前只有几何摆放，不包含已布的闭合回路。

## 4. 高速与敏感线

处理器以 MIPI 引脚朝向 J4 放置，并在 x=18.1～22.1、y=33.6～39.085 mm 留出组件禁放区。该区只禁止新增元件，不代表任意其他信号都可以占用：正式布线时应优先留给 MIPI 扇出和差分过渡。

J4 采用原有交错焊盘，P/N 两端的自然几何距离不同。必须根据真实焊盘位置调整路径与必要的长度补偿，不能把“连接器离主控近”当作差分等长已经完成。

USB 从 J1 经过 U9 保护，向 U2 引出。可考虑背面通道，避免侵占正面 FPC/MIPI 的关键空间；换层时需安排参考地回流。预留路径不等于已经验证信号完整性。

24 MHz 晶振及负载电容应优先完成短线，避免下方穿越开关节点。NAND 与 microSD 的数据/时钟按引脚分组引出，检查所用驱动强度和时序，不在未知速率下随意规定一个统一等长数值。

## 5. 过孔 0.30 mm 的边界

默认使用 0.60 / 0.30 mm 普通过孔。对相邻细间距引脚，不能每脚直接并排放同样大的过孔；需要考虑错列扇出、换层顺序和地回流。是否整个 QFN 扇出都能满足该孔径，要在实际布线中证明。

如出现局部扇出瓶颈，应先重排与调整通道，而不是默默把所有孔改小。本版没有制造出“已经全部采用 0.30 mm 孔径布通”的假象。

## 6. 收尾顺序

网络和封装审签 → 电源/晶振局部布线 → MIPI/USB 与存储 → 低速控制 → 地过孔与铜皮填充 → 真实叠层下的阻抗/压降/温升复核 → KiCad ERC/DRC、未连接清零 → 机械和丝印检查 → Gerber、钻孔、BOM、贴片坐标审签。

`critical_pad_distances.csv` 只是若干相关焊盘的中心直线距离，用于观察局部布局。它不是布线长度、不是匹配误差，也不是任何器件的数据手册合格限值。元件距离不是越小越好或越大越好，应结合完整电流回路及实际走线判断。
