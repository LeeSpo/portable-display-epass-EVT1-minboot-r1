# 唤醒中断电源域修复

更新：2026-10-04。此修改解决主控断电后中断上拉失效，以及常供电中断直接连接主控 GPIO 的电源域问题。已同步原理图、PCB、本地封装库和独立连接约束；验证结果见 `verification/wake_domain_20261004/`。实板唤醒尚未验证。

## 问题与修复

原 R17、R18 各为 10 kΩ，接在随主控关断的 `3V3` 上；RTC 和加速度计仍由 `RTC_3V3` 供电。关机后，即使两个中断输出均释放，D2/D3 与这些电阻仍会加载 `WAKE_REQ_N`。在 RTC_3V3 = 3.3 V、3V3 = 0 V、二极管压降 0.2–0.4 V 的简化模型中，WAKE_REQ_N 仅约 1.23–1.37 V，低于 U6 在 3.0–3.6 V 供电时的 2.0 V 高电平门限。该模型还未计入主控 GPIO 钳位电流，不能据此认定原电路能够重新准备下一次唤醒。

R17、R18 现改接常供电的 `RTC_3V3`。原始中断仍直接参与 D2/D3 的低有效二极管或逻辑，经 U6、Q1 拉低 PMIC 的 PWRON_N；主控接收中断的支路改经 U11 隔离。

| 部位 | 修复后的连接 |
|---|---|
| R17 / R18 | 10 kΩ，上拉至 RTC_3V3 |
| RTC 原始中断 | U5.2 / RTC_INT_N → D2.1、R17.2、U11.1 |
| 加速度计原始中断 | U4.12 / ACCEL_INT_N → D3.1、R18.2、U11.3 |
| RTC 主控中断 | U11.6 / RTC_INT_SOC_N → U2.24 / PE7 |
| 加速度计主控中断 | U11.4 / ACCEL_INT_SOC_N → U2.30 / PE6 |
| U11 电源 | U11.5 → 3V3；U11.2 → GND |
| C52 | 100 nF / 0402，U11 本地 3V3 去耦 |

U11 指定 **TI SN74LVC2G17DBVR，LCSC C10429**，双路非反相施密特缓冲器；不可用没有断电输入容忍和 Ioff 保证的通用逻辑器件直接替换。DBV6 的物理引脚为 1=1A、2=GND、3=2A、4=2Y、5=VCC、6=1Y。它随主控供电，电源关闭时允许输入端保持常供电域电压，并支持部分断电隔离；正常供电时向主控输出同极性逻辑电平。

TI 规格给出输入漏电 ±5 µA，以及 VCC = 0 时、规定测试条件下的 Ioff ±10 µA。这是有界漏电，并非“绝对零电流”。仅以 5 µA 输入漏电计算，10 kΩ 上拉的压降为 50 mV；这不能代替传感器、二极管漏电、温度、污染和完整门限裕量的实测。

新建 `Sameat:SN74LVC2G17_DBV6` 封装按 TI DBV0006A 推荐 land 核对：焊盘 1.1 × 0.6 mm，两排中心距 2.6 mm，同排节距 0.95 mm，圆角 R0.05 mm。原主控的细间距引出线予以保留；已有加速度计 In2 跨接归入缓冲器输出网络，常供电原始网络与其铜连接已分开。

## 固件和上电条件

- PMIC 必须在关机期间保持 RTCLDO1 / RTC_3V3 的目标电压。当前 C3036461 的出厂配置仍需确认，本修复不提供该项证据。
- LIS2DW12 的 INT1 要配置为**低有效、开漏、锁存**。复位默认状态不可代替关机前的明确配置。RTC 同样使用低有效锁存中断。
- 关机前清除已处理的中断，确认两路原始中断及 WAKE_REQ_N 已释放为高电平，且 U6 脉冲已经结束。避免连续边沿使 U6 重触发、延长 PWRON_N 低电平。
- PE7、PE6 仍保持原引脚和低有效极性；新增网络名仅表示缓冲后的电气节点。启动时待 3V3 和缓冲输出稳定，再清除待决中断并开启 GPIO 中断。不要依赖 U11 在电源爬升区间的输出状态。
- I²C 上拉保持在主控 3V3 域，关机前停止总线事务；不要把这两颗上拉一并迁到常供电域。R12 / C23 的约 3 s 名义唤醒定时见 [定时修复记录](WAKE_PULSE_REPAIR_CN.md)。

## 验证与实板验收

本轮静态验收已通过：KiCad 原生 ERC、完整 DRC、未连接、原理图一致性均为 0；152 项独立逐引脚约束通过，118 个电气器件 / 499 个编号焊盘与原生网表一致，82 个非 NC 网络的焊盘各为一个连通组。唤醒域拓扑检查和 USB 回归检查通过，新增过孔没有进入 SMD 焊盘。`negative_checks.json` 注入六种故障：任一路上拉回到 3V3、主控直连原始中断、U11 改用常供电、未经验证的替代型号、U11 漏装；均必须被检查器拒绝。当前报告中的 `hardware_verified` 保持为 false。

实板需要分别验证 RTC 和加速度计：保持 RTC_3V3、关闭主控 3V3，测量原始中断和 WAKE_REQ_N 的释放电平；观察关闭电源轨的残余电压和漏电，确认没有被中断信号抬升。触发单次事件，测量 WAKE_REQ_N、U6.Q、PWRON_N、3V3，确认能够启动且 PWRON_N 低脉冲落在 2.2–3.8 s 验收窗口内。清除事件并再次关机，验证两路均可反复唤醒，同时覆盖低电量、温度和中断连续触发情形。

现有 D2/D3 仍为通用 BAT54 标注及原 SOD-123 land；实际采购型号、阴阳极映射和低电平裕量需绑定实物确认。此处保持既有二极管网络，不能把本次电源域修复当作二极管选型或整板功能放行。

- `tools/test_wake_domain.py`：故障注入回归检查。
- `power_requirements.json` 与 `tools/check_power_contract.py`：元件装配、型号、逐引脚连接和原生网表一致性要求。
