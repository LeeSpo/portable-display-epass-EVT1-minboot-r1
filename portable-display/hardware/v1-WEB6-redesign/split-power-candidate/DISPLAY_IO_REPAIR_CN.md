# 屏幕 RESET / TE 电平修复

2026-09-24，修订 LCD-IO1。已修改主 PCB、原理图及独立检查约束。通过使用空闲的 1.8 V GPIO，消除屏幕控制信号与原 3.3 V GPIO 的电平不匹配；并增加复位下拉。硬件静态检查已通过，固件迁移和实板点屏仍待验证。

## 最终连接

| 信号 | 修改前 | 修改后 |
|---|---|---|
| LCD_RST → J4.16 / RESX | U2.2 / PD19，3.3 V 域 | U2.66 / PA8，1.8 V 域，低有效 |
| J4.15 / TE → LCD_TE | U2.3 / PD20，3.3 V 域 | U2.65 / PA9，1.8 V 域，支持 PA-EINT9 |
| 复位默认状态 | GPIO 高阻，无外部下拉 | 新增 R32，10 kΩ、0402、1%，LCD_RST → GND |
| 屏幕逻辑供电 | 1V8 经 R29 / 0 Ω 到 LCD_1V8 | 保持，明确要求 R29 必须装配且保持 0 Ω |

PD19 / PD20 已从这两条网络移除并标为未连接。PA8 / PA9 原先未使用；它们与屏幕 VDDIO 取自同一路 1V8（U2.62 为 PA/MCSI 供电）。不增加电平转换芯片。PA8 / PA9 因此不能再分配给摄像头、TWI、PWM 或 UART 复用功能。

R29 的旧备注“后续可换负载开关”已移除：若以后独立切断屏幕 VDDIO，必须重新设计 GPIO 隔离和掉电时序，不能直接沿用本次共电源域的连接。

## 依据与电平裕量

- 项目内全志引脚表 `../reference/v851s_pinout_v0.1.xlsx`：PA8=66 脚、PA9=65 脚，属于 VCC-PA&VCC-MCSI；默认高阻。Function 14 为 PA-EINT8 / PA-EINT9。原 PD19 / PD20 属于 VCC33-PF&PD。
- [全志 V851S/V851SE 数据手册](https://bbs.aw-ol.com/assets/uploads/files/1664112156052-c55b9458-9847-4731-873e-c98d352589ea-v851s-amp-v851se_datasheet_v0.1.pdf)：表 2-6 给出 PA 域 1.62–1.98 V；表 2-7 给出 GPIO VIH≥0.7×供电、VIL≤0.3×供电、VOH≥供电−0.2 V、VOL≤0.2 V，高阻漏电流上限 ±10 µA。
- 已核对原始屏幕 PDF `../../../docs/kd024_screen/raw-pdf/KD024EGOIN152-01 SPEC V1.pdf`：PDF 第 13 页（印刷 14/25）定义 TE 输出和低有效 RESX；PDF 第 22 页（印刷 23/25）规定输入 VIH≥0.8×VDDIO、VIL≤0.2×VDDIO，输出 VOH≥0.8×VDDIO、VOL≤0.2×VDDIO。VDDIO 典型 1.8 V。

按本板 1V8 的既定要求 1.70–1.95 V、PA 与 VDDIO 共电源计算，最小静态裕量如下。此计算不包含布线噪声、地弹和瞬态供电压降。

| 方向 / 状态 | 最小裕量 |
|---|---:|
| PA8 输出高 → 屏幕 RESET 高 | 0.14 V |
| PA8 输出低 → 屏幕 RESET 低 | 0.14 V |
| 屏幕 TE 高 → PA9 高 | 0.17 V |
| 屏幕 TE 低 → PA9 低 | 0.17 V |

R32 在 GPIO 高阻时将 RESET 下拉，单独计入主控 10 µA 高阻漏电和 1% 阻值误差，电压约不超过 0.101 V；屏幕端未给出的漏电和启动瞬态仍需实测。RESET 释放到 1.8 V 后，下拉电流约 0.18 mA、功耗约 0.324 mW。

## PCB 与检查

新增 R32 位于 (11.5, 35.3)，旋转 90°；补充一个接地过孔连接参考地。RESET / TE 重新布线；器件禁布区和原工程规则保持。新增信号过孔已检查，没有钻入 SMD 焊盘；既有器件位置、封装、其余信号及电源走线不变，之前 TF 默认上电修复保留。

原生 KiCad 10.0.6：DRC 0 违规、0 未连接、0 原理图一致性问题；ERC 0 违规。116 个电气器件、491 个编号焊盘、全部器件值与原理图一致；95 项独立引脚要求和必装器件约束通过。将 PD19 重新接到 RESET、PA 域改成 3.3 V、漏装 R29、漏装 R32 四种故障注入检查，均被拒绝。

## 固件与实板验收

1. 本仓库未发现对应固件或设备树。接入固件时，将原 PD19 的屏幕复位迁移到 PA8（低有效），原 PD20 的 TE 输入/中断迁移到 PA9 / PA-EINT9。禁止把 PA9 配为输出；关闭无关摄像头/TWI/PWM/UART 复用。PA8 高阻期间不要启用上拉。
2. 初始化时保持 RESET 为低，待屏幕所需各路电源按厂家时序稳定后，再产生规定复位脉冲并释放。具体电源先后、复位脉宽和等待时间必须依据驱动资料与实测确定，本次没有虚构固定时序值。
3. 示波器观察 LCD_1V8、LCD_RST、LCD_TE：确认复位不出现 3.3 V、默认保持低，释放电平和时序正确；发送 TE 使能命令后确认 PA9 能稳定接收中断，且休眠/唤醒不会误触发。
4. 本项不等于整屏已可点亮：AXP2101 默认配置、屏幕 EL± 电源工作点、VCI/偏压时序、MIPI 走线和 J4 最终机械接口仍需完成各自验收。
