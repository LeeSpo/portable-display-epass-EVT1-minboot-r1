# 电源审查与平台料要求

2026-09-20；对象：本目录 38×64 mm 四层候选。用户计划由嘉立创使用平台料贴片。

**状态：配套原理图已恢复并与 PCB 核对；电源冷启动问题尚未关闭。** U1 平台料号为 C3036461，平台公开信息没有确认该料号/批次的上电电压、默认使能和顺序。不能把这次原理图同步或 ERC/DRC 通过表述为“电源已修好、可直接贴片上电”。本次没有改变 PCB 铜线、焊盘、元件值或布局。

## 1. 本次落实的修复

- 新建与本工程同名的顶层原理图及电源、SoC、传感器、接口四张子图。115 个电气器件来自当前 PCB；4 个无编号电气焊盘的机械孔不作为电路元件。
- 原理图跟进此前 PCB 的正确修正：U1-36/C38 属于独立 VMID；U2-37/62/79 使用外部 1V8；U2-14/C34/C37 保持内部 LDOA 网络；U6 同步当前已经核实的物理脚序。没有把旧原理图的错误连接重新带回。
- 电源输出和输入具有 ERC 类型；U1-36 按手册设为 power_out；PC2/PC3 按 GPIO 启动绑带标为双向。电感后和电池/USB 输入的供电标志仅表示连接拓扑，不保证默认电压。
- 提供独立电源引脚约束、原生网表逐脚比对及电源需求表。该次同步时的电气问题（TF、唤醒、屏幕电平、高速走线）没有随原理图恢复而解决。2026-09-21 已另行完成 [TF 默认上电电路修复](TF_POWER_REPAIR_CN.md)，2026-09-24 另行完成 [屏幕 RESET/TE 电平修复](DISPLAY_IO_REPAIR_CN.md)。其余项和实板验收仍未关闭。

以下目标是本设计需求，**不是 C3036461 的已知默认值**。电压范围来自 V851S 数据手册 2.3.4，表 2-6；正常目标还须留出负载压降、纹波和器件误差裕量。

|---|---|---|---|---|
| VBUS | J1 USB-C → U1-37；C32 去耦 | AXP2101 输入 | USB 5V | AXP2101 工作输入 3.9–5.5V |
| VBAT | J2-1 → U1-33；C3 去耦 | 单节电池路径 | 待最终电池规格 | 充电终止电压、电流及 NTC 尚未按电池定版 |
| VSYS | U1-34；C1/C2 储能 | U1-6/7/23/24、屏幕偏压输入 | 随电源路径工作 | 不是固定 3.3V/5V；U10 输入上限另须验证 |
| 3V3 | DCDC1：U1-22 → L1 → 输出；U1-21 反馈 | U2-5/22/44/47/55/78；U1-13/17 | 3.30V，上电启用 | SoC 3.3V 电源 2.97–3.63V；需先建立 |

| DRAM_1V5 | DCDC4：U1-8 → L3；U1-9 反馈 | U2-34/36 | 1.50V，上电启用 | 1.425–1.575V 档；采购时确认 V851S 内置 DRAM 版本 |
| 1V8 | U1-17 由 3V3 供电；ALDO1 U1-18 输出 | U2-37/62/79；ADC 上拉及 LCD_1V8 | 1.80V，上电启用 | U2-37：1.70–1.95V；U2-62/79：1.62–1.98V；ALDO1 最大 300mA 不是本板已验证负载能力 |

| SOC_LDO_1V8 | U2-14，C34/C37 去耦 | 内部 LDOA/PLL | 内部约 1.8V | 1.62–1.98V；不得与 ALDO1 并联 |

| VMID | U1-36，C38 去耦 | PMIC 内部中间电源输出 | 按 PMIC 应用电路 | 不与 VSYS 相连 |

## 3. 冷启动时序要求

V851S 文档正文 26–27 页（PDF 40–41 页），2.3.5/图 2-2：

1. VCC33-PF&PD 首先建立；本板对应 DCDC1 的 3V3。
2. 内部 LDOA/PLL 稳定后，核心供电满足至少 1ms 的时序要求。正文表述为核心开始上升前至少 1ms；图的 T1 标记与正文有表达差异，验收采用正文较保守的要求，最终以厂家确认及实测为准。
3. 核心供电与内部 Reset 释放之间至少 8ms；该 Reset 标注为 **Internal**，不是 U2-45/PH0，也不是 LCD_RST。不要为了“补复位”把 PWROK 接到任意 GPIO。
4. 24MHz 时钟在内部 Reset 释放后约 4ms 起振。同步观察 DRAM、外部 1V8 的建立过程及掉电行为。

AXP2101 默认输出和启动顺序由定制/EFUSE 决定；I²C 上电后写寄存器不能证明第一次冷启动满足上述条件。当前没有预启动控制器，也没有针对 C3036461 批次的默认配置证据。

## 4. 与嘉立创/立创确认的具体内容

### 官方参考板可以支持的推断（补充复核）

已逐图查看全志 V851S-PER2 V1.2，2022-07-05 的第 1、3、7 页，而非仅按网络名称推测。

| 项目 | 官方图直接证据 | 本板对照与结论 |
|---|---|---|
| 核心目标 | 第 1 页修订记录明确由 0.9V 改为 0.93V；第 7 页 DCDC3 标 0.93V(ON) | 本板 DCDC3/CORE_0V93 有直接参考依据；第 3 页旧 0.9V 标签不能覆盖更新记录 |
| 主 IO、DRAM | 第 7 页 DCDC1=3.3V(ON)、DCDC4=1.5V(ON) | 本板三路主 DCDC 分配和目标与该官方方案一致，可继续以此为设计基线 |
| 外部 1.8V | 第 7 页 BLDO1 经 RP89 等给外设供电，RP34/RP29 接向 VDD18-DRAM、VCC-PA&MCSI、VCC18-MDSI；内部 LDOA 接入用 RP40 标 NC | 本板外部 1.8V 与内部 LDO 隔离有依据，但本板用 ALDO1，未完全照搬官方 BLDO1 通道；第 3 页虽然标 ALDO1=1.8V(ON)，不能因此忽略通道差异 |
| RTC | 电源树和第 7 页标 RTC 3.3V | 支持本板 RTC_3V3 的目标值；仍不能证明平台批次的默认值 |
| 未用通道 | 第 3 页 DCDC2 标 ON，第 7 页其电感/电容又标 NC | 参考图存在配置/装配选项，不能推断本板未用通道默认关闭，更不能将“NC”直接等同“关闭” |

该文件名、框图及第 7 页大字说明指向 **AXP2102 开关充电**，但 PMIC 符号仍写 AXP2101，若干旧网络名也保留 AXP2101。充电、电源路径及 SW/VMID 等必须继续以所选 C3036461 的 AXP2101 线性充电版手册核对，不能照抄此板。该官方图另含 XR806 控制部分，当前板没有该器件。

**工程决策：可以采用官方电源配置作为候选设计假设继续推进，无须仅因缺少平台回复就推翻现有三路 DCDC；但不得把这一推断写成现货 OTP 已核实或冷启动已通过。** 外部 1.8V 通道差异、未用输出及实际时序仍需独立确认。本次只补充依据，没有切换 ALDO/BLDO 的 PCB 接法。

公开页面已核对 C3036461 = AXP2101、QFN-40-EP(5×5)，并支持贴片。**这不等于确认 OTP 配置，也不等于平台会按原理图网络名称烧录 PMIC。**

可将以下文字发给平台技术支持/元件供应商（本次未代发）：

> 我们使用贵平台 C3036461 AXP2101，计划直接 PCBA 贴片。请提供该在售料号及供货批次断电重启后的出厂 EFUSE/OTP 输出电压、默认使能和启动顺序表。设计使用 DCDC1=3.3V、DCDC3=0.93V、DCDC4=1.5V、ALDO1=1.8V，以上必须无需主控写寄存器即开启；RTCLDO1 目标 3.3V 并在 PMIC 关机状态保持。DCDC2/DCDC5 未布置电感，必须默认关闭。请确认 3.3V 先上电、V851S 内部 LDOA 稳定至少 1ms 后核心供电再上升，及芯片 PWRON 模式、VBUS 插入自启动和充电默认配置。若现货不满足，请明确是否提供有独立可追溯料号的匹配配置，或出厂配置无法保证。

收到回复后的处理规则：

- 若默认配置兼容，则以供应商文件和批次绑定采购条件，再实测冷启动。CORE 默认 0.90V 是否可接受应按目标频率/芯片要求审核，不能仅因网络名是 0V93 判为损坏。
- 若 ALDO1 默认关闭，不能指望从 TF 启动后才打开必需的 DRAM 1.8V 电源。
- 若任意默认电压超出负载范围或时序不兼容，需要修改电源架构/电源分配；不能用软件补丁承诺解决启动前问题。
- 若平台不能提供默认配置保证，第一项继续保持未关闭。另行设计外部确定电压/时序的供电方案属于电源架构重做，不应偷偷替换本板 PMIC。
