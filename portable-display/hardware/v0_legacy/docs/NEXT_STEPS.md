# 下一阶段完成顺序

## A. 把设计输入定下来

取得具体屏幕模组数据手册，确认当前 58 x 110 mm 板形是否容纳模块、FPC 弯折与外壳。取得实际采购 AXP2101 的配置和参考电路，核对所有电源、VMID/VSYS 和上电顺序。对 U1/U2/连接器和其他 IC 的针脚与封装逐个审签。

## B. 在原生 KiCad 中建立可信检查基线

本机已用 KiCad 10.0.6 跑通 `tools/verify_evt1.py` 路径。当前非显示检查通过；设计变更后继续复查最新 native 报告中的未连网络、悬空过孔和 warning，不通过更改严重程度、删除报告或扩大豁免绕过。

## C. 最小系统布线完成后的审查

非显示网络已全部连通，当前原生 ERC / DRC / 原理图一致性检查通过，详见 `MINBOOT_ROUTING.md`。不要继续按旧的几何分组数量判断飞线是否未完成；该统计不包含覆铜连接。

接下来依据实际 AXP2101 配置确认电压与时序，检查电源短环路、去耦、载流与温升；依据板厂叠层确认 USB / SD 等走线的阻抗、回流和时序。USB 已采用并行主干，但尚未完成阻抗和电气长度审签。然后准备启动固件、设备树和限流上电计划。

## D. 显示定版与整板关闭问题

按最终屏幕复核供电、FPC 针脚、DSI 极性和时序、背光驱动；完成布局与布线，再取消显示未连豁免。对全板生产规则、装配、可测试性、保护和机械结构复核。

## E. 发布制造输入与实物验证

所有 `release_gates.json` 项目有明确审签人与证据后，检查同一版本的全量原生报告；再由最终 PCB 生成并复核制造包。首板验证按已批准的上电计划逐步执行。完成此阶段前，不应命名为量产版或声称已经可用。
