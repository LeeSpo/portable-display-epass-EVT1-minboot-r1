# 上电前置条件与后续验证

**当前版本禁止直接作为上电样板使用。本文件是待完善的验证计划，不是已批准操作规程。**

## 投板前

先完成所有所需布线，并对指定版本的 V851s / AXP2101 数据手册、参考设计、OTP 配置和器件封装逐项核对。明确电池极性、保护和温度检测，核对充电电流与电感/电容/散热能力。确认每一路供电的实际允许范围和时序，而非只根据网络名称或旧文档的固定百分比判定。

运行新鲜的完整 KiCad ERC、DRC、覆铜重填和原理图一致性检查。任何未解释的警告、错误、短路、非显示未连或缺失报告都必须阻断；正式投板时显示也不能继续白名单豁免。核对最终 PCB 导出的 BOM / CPL / Gerber / 钻孔文件，不能使用 reference 下的历史输出。

## 样板验证顺序（前置条件全部通过后）

先进行无源短路、极性和装配检查，再由硬件工程人员制定并使用限流电源进行分阶段上电。电池和显示模组在各自供电、连接器与保护确认前不接入。具体限流值、电压上下限、启动时序和停止条件，须根据最终设计的预算与器件资料填写，当前不猜测数值。

验证 PMIC 默认电压、时序、纹波、异常温升和掉电行为后，再依次验证时钟/复位、调试串口与 USB 启动通路、存储器、SD、传感器与唤醒。屏幕逻辑和背光应分开验证，并按最终模组数据手册确定初始化和电流，不能沿用旧文档未经确认的背光目标。

固件、设备树、引脚复用、启动介质内容和实物测量记录不包含在本次完成项中。应对每一步记录板号、工程版本、仪器、测量值、现象和审签人员。
