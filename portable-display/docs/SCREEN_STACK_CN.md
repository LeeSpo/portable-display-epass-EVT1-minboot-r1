# 屏幕与 PCB 的装配评估

## 本次用户提出的方案

允许增加整机厚度，让屏幕通过支撑结构架在 PCB 上方。建议评估的层次为：

**显示面 → 屏幕及其背面 FPC → 支撑间隙 → PCB 正面元件 → PCB → 后壳。**

这是“元件朝向屏幕”的装配方式，与旧 README 中“元件背向屏幕”的假设不同。
PCB 中的 F.Cu/B.Cu 只定义板面，不能单独证明整机中哪一面朝屏幕。
当前贴装正面 117 颗、背面 13 颗；两侧元件均应纳入装配高度包络。

## 从屏厂图纸能够确认的事实

来源：`kd024_screen/raw-pdf/KD024EGOIN152-01_SPEC_V1.pdf`，第 5～6 页。

- 屏幕外形为 38.72 × 51.56 mm；有效显示区为 36.72 × 48.96 mm。
- FPC 出厂为展开状态。第 6 页给出了向屏幕背面折回的示意，插接端位于背面的上部。
- 图纸区分了 FPC 器件区、弯折区、补强和点胶区。不能把整条排线都当作可任意折叠的薄膜。
- 配套连接器型号为 Molex 502598-4591。
- 折回图是结构示意，没有提供与本 PCB 安装孔关联的装配坐标、支撑高度或完整公差链。

## 可行性判断

**加高并用支撑框承托屏幕，在结构上可行；目前资料不足以签核具体间隙数值。**

间隙应逐区域核对：对于屏幕后方 FPC/器件与 PCB 元件发生平面重叠的位置，
所需空间是两侧突出高度之和，再加装配公差及防接触余量。
没有平面重叠的器件不需要机械地把所有高度相加。
不能仅按 SoC 的高度决定整个屏幕与 PCB 的距离，也不能把玻璃厚度当作屏幕模组总厚度。

屏幕应由独立承托框或屏厂允许的支撑面承力，不由芯片、电感、连接器或 FPC 元件顶住。
支撑应避开有效显示区、COF 连接、点胶和 FPC 弯折区。PCB 的四个安装孔主要用于固定 PCB；
孔位处的螺丝头也需要计入屏幕下方的高度包络。

## J4 的实际限制

现有 J4 位于 F.Cu、板内坐标约 (16,43) mm，插接预留区位于其下方。
在旧图假设的“屏幕居中、顶边与 PCB 对齐”条件下，它位于屏幕投影的下部。
这与屏厂折回示意中插接端到达背面上部的形态不一致。

**增加 Z 向高度不会自动修正 J4 的 X/Y 位置、接触面或针 1 方向。**
如果采用“屏幕架在正面元件上方”，J4 可以继续位于 F.Cu，但仍应根据折回后排线端的位置
重新定位并核对连接器开口、触点面和编号。若采用“PCB 背面靠屏幕”，则应另外评估 B.Cu 屏座
或结构开槽；不能直接把该方案与正面屏座混用。

当前电气选型为 Molex 502598-4593 / C5365339；与屏幕规格列出的 -4591 及实物 FPC 的机械兼容仍未签核。
正式移动 J4 之前应建立屏幕、FPC、连接器和 PCB 的同一套装配基准，完成排线插入与折弯检查；
随后再调整 U2 的 MIPI 出线方向。不能为保留现有 J4 而假设额外折痕成立。

## 外形边界

PCB 仍为 38 × 64 mm。按顶边对齐放置，PCB 尾部会比屏幕长 12.44 mm。
增加厚度不会消除这一平面外形差异。外壳需容纳板尾接口区；当前并非完全隐藏于屏幕后方的主板。

## 下一步可签核条件

1. 明确屏幕相对 PCB 的平面基准及朝向。
2. 用实际连接器与排线确认针 1、触点面和插入方向。
3. 获取重叠区域最高器件及 FPC 器件高度，确定可制造的支撑间隙。
4. 检查屏框、螺丝、USB、TF 卡及按键的装配和操作空间。

这些条件尚未关闭，当前工程仍未放行生产；状态见 [未完成项](../hardware/v1-WEB6-redesign/split-power-candidate/OPEN_ISSUES_CN.md)。
