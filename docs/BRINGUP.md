# 上电与验证计划（含电源分阶段）

**当前版本禁止直接作为上电样板。** 本文给出可执行的候选规程；限流值与 OTP 结论须在实物填写后，经人工审签才可执行。

## 投板前（电源相关）

1. 合并并审阅 `docs/POWER_AXP2101.md`、`POWER_LAYOUT_CHECKLIST.md`。  
2. BOM 中 PMIC 为 **`C3036461`**；电池 NTC **10 k**；电感 1 µH 饱和电流满足 §POWER。  
3. 新鲜 ERC/DRC；显示未连豁免仅允许在「无屏调试板」明确声明时存在——**带屏投板不得豁免显示网**。  
4. `design/release_gates.json` 中 `pmic_variant` 的 OTP 附录已填且结论为通过。  
5. 导出本版本 Gerber/BOM/CPL；禁用 `reference/` 历史包。

## 电源分阶段（候选）

仪器：限流电源、万用表、（可选）电流探头 / 热像。

### A. 仅 PMIC 烟测（建议先做 OTP）

1. **不装** SoC 大负载也可：或装板但软件不启动——优先「能探到 FB/输出测试点」。  
2. USB-C 口馈电：台架设 **5.0 V，限流 0.3 A** 起步。  
3. 测量并记录：`VSYS`、`3V3`、`CORE_0V93`、`DRAM_1V5`、`1V8`、`RTC_3V3`、`VREF`。  
4. 填入 `POWER_AXP2101.md` 附录。  
5. 若 `DRAM_1V5` 实测 ≈1.1 V：标记 OTP 不匹配——**禁止**在未改压前跑满负荷 DDR；须 I2C 改 DCDC4 或换批次。  
6. 无冒烟、无过热（壳温经验阈值 <85 °C @0.3 A 输入）再升限流。

### B. 充电路径

1. 接入带 10 k NTC 的电池（或等效）；台架仍限流。  
2. 固件/`axp2101` 参数：充电电流 **0.5–0.8 A**，确认 TS 使能。  
3. 观察 `CHGLED`、电池端电压与芯片温度。

### C. SoC / 存储 / USB

1. 确认核电与 DRAM 已正确后再允许 boot。  
2. 串口、USB 枚举、NAND/SD 按原计划。  
3. 再接显示模组（逻辑电与 EL 分步）。

## 停止条件（任一出现即断电）

- 任一轨超过目标 ±10% 且无法解释  
- 限流电源恒流跌落伴随焦糊味 / 热点  
- DRAM 或核电过压  
- 电池极性或 NTC 开路却仍大电流充电

## 固件注意

- 设备树 / U-Boot 显式设置 DCDC1=3.3 V、DCDC3≈0.9 V、DCDC4=1.5 V、ALDO1=1.8 V。  
- 电量计 128 参数：量产前寄电池测；EVT 可暂用电压估算并在文档声明。
