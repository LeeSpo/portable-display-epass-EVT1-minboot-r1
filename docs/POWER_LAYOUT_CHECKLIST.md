# AXP2101 PCB Layout 勾选（投板前人工）

依据《AXP2101 设计指南》§5。在 KiCad 打开 `board` / 本分支同源 PCB 后逐项勾选。

## 大电流

- [ ] `VBUS`、`VMID`/`VSYS`、`VBAT` 线宽或覆铜等效 **>150 mil**
- [ ] 各 DCDC `VIN*`、`LX_*` **>150 mil** 或短而宽的覆铜
- [ ] 电池座到 `VBAT` 尽量短、粗
- [ ] 回流地完整，功率地与 `VREF` 地单点策略合理

## 噪声

- [ ] `VREF` 电容紧贴引脚；接地点远离 LX 开关节点
- [ ] L1/L2/L3 靠近 U1；输出电容靠近电感负载侧
- [ ] 输入电容靠近对应 VIN；电流先经电容再进 pin
- [ ] 芯片下方 / 邻层为地平面（本板 4L：器件层下为地为佳）

## 装配

- [ ] U1 热焊盘接地过孔充足
- [ ] 电感焊盘与 LX 无细颈
- [ ] NTC/电池座极性丝印清晰

**全部勾选前不得将 `fabrication_released` 置 true。**
