# U2 过孔 0.3 mm 扇出可行性验证（2.4″ AOD 假设）

> Branch: `feat/u2-via-0p3-fanout-verify`（从 `board` 拉出）  
> 状态：几何分析结论；**尚未**在本分支改写完整 PCB 扇出（云端改板不可用时先落文档+检查脚本）  
> 假设屏幕：约 **2.4″ AOD AMOLED**（RM690B0 / ICNA3312 族，外形约 39×52 mm），板框仍 **58×110 mm**

## 1. 问题回顾

当前 EVT1：`via pad 0.40 / drill 0.20`。  
U2 附近已是 dogbone + 错位扇出，不是“孔还夹在 0.35 mm 脚缝里”。  
仍用 0.2 的原因是：**扇出环上过孔彼此间距过密**——中心距最小约 0.57 mm，0.40 盘铜间隙约 0.17 mm；若改 0.50 盘 / 0.30 钻，同位置约二十多对孔间隙会掉到约 0.07 mm，DRC 不过。

## 2. 空间够不够？还能不能再往外？

对 `board` 上 `portable_display_epass.kicad_pcb` 实测（单位 mm）：

| 项 | 数值 |
|----|------|
| 板框 | 58 × 110 |
| U2 中心 | ≈ (30, 56)，大致居中 |
| U2 到四边 | L/R/T/B ≈ 30 / 28 / 56 / 54 |
| 现有过孔环半径 | 约 0～12（中位 ~8） |
| 到板边剩余 | 最小边距 − 环半径 ≈ **16 mm**（板边不是瓶颈） |
| U2 附近最近器件 | C35≈10.0，C36≈10.2，C37≈10.3，Y1≈11.0 |

**结论（空间）：**

- **相对板边：够大，还能再往外扩一圈扇出。**
- **相对现布局：不够“空”。** 去耦/晶振大概在 10 mm 圈上，过孔环已经顶到 ~12 mm——再扩必须先 **外移这些 0402/0603/晶振**，否则孔会撞焊盘。
- 换 **2.4″ 屏** 主要释放的是 **显示开窗/外壳堆叠** 面积（相对 4.4″ 左右约多出 ~19×58 mm 量级余量），**不自动清空 U2 周围器件**。但板面更空之后，**有地方把 C35 一带电容和 Y1 往外挪**，给 0.3 孔腾扇出环——这是 2.4″ 假设带来的真实红利。

## 3. 要上 0.3 需要满足什么

经验目标（需按嘉立创当时规则再核）：

- drill **0.30**，via pad 建议 **≥ 0.50～0.55**（留环形）
- 过孔中心距建议 **≥ pad + clearance**（例如盘 0.50、间隙 0.15 → 中心距 ≳ 0.65；更稳可按 ≥0.70～0.80）
- 现最小中心距 0.57 → 至少要把最密的那批孔 **再拉开 / 外推**，或减少孔数（更多同层直连）

推荐步骤：

1. 以 U2 为中心规划 **外径 ≥ 14～16 mm** 的扇出环（视挪件后可用空间）。  
2. 将 C34–C37、C14–C18、Y1 等让出扇出走廊。  
3. 狗骨头加长 + 交错，目标最小孔距达标后再统一改孔径。  
4. USB/MIPI 差分区禁止为了错位乱绕。  
5. 全量 DRC；本分支验证通过前 **不** 改 `fabrication_released`。

## 7. 2026-09-05 挪件试做结果（本分支 PCB）

在假设 2.4″ 屏、允许外移近端阻容的前提下，对 `portable_display_epass.kicad_pcb` 做了自动化试改：

### 已做
- 外移 U2 约 16 mm 内阻容/晶振等 15 个器件：`C12–C18,C28,C34–C37,D5,R27,Y1`（径向推出，目标距离 ≳14.5 mm）
- 扩大 U2 邻域过孔环，并将该邻域过孔改为 **pad 0.50 / drill 0.30**
- 对过近孔对做分离迭代

### 几何检查
```text
python3 tools/check_u2_via_pitch.py portable_display_epass.kicad_pcb --radius 26
→ RESULT: PASS（0.50 盘下 pairs_below_0.15 = 0）
```

板外过孔：0。U2 邻域（26 mm）内过孔现为 0.30；板其它区域仍保留原 0.20。

### 重要警告（必读）
1. **只验证了“孔距/器件让位”几何，没有自动重连全部扇出走线。** 过孔挪位后，原狗骨头铜线端点会大量悬空，**打开 KiCad 会看到飞线/断网**，不能当可投板文件。
2. 未跑完整原生 DRC/ERC 放行；`fabrication_released` 仍应为 false。
3. 电容外移可能拉长电源去耦路径，电气上还要人工收紧（优先把高频去耦再贴回 U2 附近但避开孔阵）。
4. USB/MIPI 差分未在本脚本中专项保护，需目视检查是否被过孔阵侵入。

### 结论
- **空间上：2.4″ + 挪件后，0.3 mm 孔阵几何可行（脚本 PASS）。**
- **工程上：还差手动/半自动重布 U2 扇出铜线 + 去耦回流优化 + 原生 DRC。**
