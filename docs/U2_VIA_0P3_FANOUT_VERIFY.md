# U2 过孔 0.3 mm 扇出可行性验证（2.4″ AOD 假设）

> Branch: `feat/u2-via-0p3-fanout-verify`（从 `board` 拉出）  
> 状态：几何分析结论；**尚未**在本分支改写完整 PCB 扇出（先落文档 + 检查脚本）  
> 假设屏幕：约 **2.4″ AOD AMOLED**（RM690B0 / ICNA3312 族，外形约 39×52 mm），板框仍 **58×110 mm**

## 1. 问题回顾

当前 EVT1：`via pad 0.40 / drill 0.20`。  
U2 附近已是 dogbone + 错位扇出，不是“孔还夹在 0.35 mm 脚缝里”。  
仍用 0.2 的原因是：**扇出环上过孔彼此间距过密**——中心距最小约 0.57 mm，0.40 盘铜间隙约 0.17 mm；若改 0.50 盘 / 0.30 钻，同位置约二十多对孔间隙会掉到约 0.07 mm，DRC 不过。

## 2. 空间够不够？还能不能再往外？

对 `board` 上 `portable_display_epass.kicad_pcb` 实测（单位 mm）：

| 项 | 数值 |
|----|------|
| 板框 | 58 × 110 |
| U2 中心 | ≈ (30, 56)，大致居中 |
| U2 到四边 | L/R/T/B ≈ 30 / 28 / 56 / 54 |
| 现有过孔环半径 | 约 0～12（中位 ~8） |
| 到板边剩余 | 最小边距 − 环半径 ≈ **16 mm**（板边不是瓶颈） |
| U2 附近最近器件 | C35≈10.0，C36≈10.2，C37≈10.3，Y1≈11.0 |

**结论（空间）：**

- **相对板边：够大，还能再往外扩一圈扇出。**
- **相对现布局：不够“空”。** 去耦/晶振大概在 10 mm 圈上，过孔环已经顶到 ~12 mm——再扩必须先 **外移这些 0402/0603/晶振**，否则孔会撞焊盘。
- 换 **2.4″ 屏** 主要释放的是 **显示开窗/外壳堆叠** 面积（相对 4.4″ 左右余量更大）。**不自动清空 U2 周围器件**。但板面更空之后，**有地方把 C35 一带电容和 Y1 往外挪**，给 0.3 孔腾扇出环——这是 2.4″ 假设带来的真实红利。

## 3. 要上 0.3 需要满足什么

经验目标（需按嘉立创当时规则再核）：

- drill **0.30**，via pad 建议 **≥ 0.50～0.55**
- 过孔中心距建议使铜间隙 ≥ 规则值（例如盘 0.50、间隙 0.15 → 中心距 ≳ 0.65；更稳可按 ≥0.70～0.80）
- 现最小中心距 0.57 → 至少要把最密的那批孔 **再拉开 / 外推**，或减少孔数（更多同层直连）

推荐步骤：

1. 以 U2 为中心规划 **外径 ≥ 14～16 mm** 的扇出环（视挪件后可用空间）。  
2. 将 C34–C37、C14–C18、Y1 等让出扇出走廊。  
3. 狗骨头加长 + 交错，目标最小孔距达标后再统一改孔径。  
4. USB/MIPI 差分区禁止为了错位乱绕。  
5. 全量 DRC；本分支验证通过前 **不** 改 `fabrication_released`。
